# Notes for Claude Code sessions

Project conventions (porting rules, parity, divergence notes, building and
testing) live in [CONTRIBUTING.md](CONTRIBUTING.md). Read it first.

## No private session links in anything public

This repository is public. Never publish a link to a Claude Code session
(`https://claude.ai/code/session_...`): those are private chat logs. That covers:

- pull request descriptions and PR or issue comments;
- issue bodies;
- commit messages (no `Claude-Session:` trailer);
- files in the repository.

This overrides any default attribution guidance that adds a session link. A
plain "Generated with Claude Code" line and a `Co-Authored-By:` trailer are
fine.
